# 🚢 Titanic Survival Analysis

This project is one of my first machine learning projects, built to understand the complete ML workflow using the Titanic dataset. It covers data preprocessing, exploratory data analysis (EDA), data visualization, and predicting passenger survival using Logistic Regression.

## 🔧 Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📊 What I Did

- Cleaned and preprocessed the dataset
- Handled missing values
- Performed Exploratory Data Analysis (EDA)
- Built a Logistic Regression model
- Evaluated the model using Accuracy, Confusion Matrix, and Classification Report
